Key Challenges Overcome
Six critical bugs caught before shipping
The test suite (TDD red→green) and a mandatory real-API smoke run caught every critical issue before the branch was merged. Unit tests with fake LLMs cannot validate token/cost capture — the real-run step is a required gate.
Task 1
🔴 Critical — Environment
CUDA wheels filled disk to 100%
Default pip install pulled 1.9 GB of nvidia-cu13 + triton CUDA wheels onto a 32 GB drive already at ~30 GB. Install died mid-way with ENOSPC, leaving a broken partial venv.
Fix: Install CPU-only torch first via --index-url pytorch.org/whl/cpu (190 MB), then sentence-transformers skips CUDA. Used --no-cache-dir to prevent cache refill. Freed 5.6 GB; disk at 89%.
Task 2
🔴 Critical — API Composition
with_retry() → RunnableRetry has no with_structured_output
PLAN.md sketched: build_llm().with_retry() then call .with_structured_output() on the result. But RunnableRetry does not expose with_structured_output — this would raise AttributeError at runtime.
Fix: Invert the order. Apply with_structured_output(schema) to the bare ChatAnthropic first, then wrap the result with .with_retry(...). Both invariants (single seam, single retry) preserved.
Task 3
🟠 High — Correctness
re.IGNORECASE broke the section-aware chunker
The heading regex used IGNORECASE, so body-text mentions like "Section 40 provides…" also triggered a chunk split. This broke the "one exemption = one citable chunk" invariant that citation grounding depends on.
Fix: Case-sensitive anchored regex ^SECTION\s+(\d+)\b — only uppercase real headings trigger splits. TDD test test_section_aware_chunk_is_one_exemption caught it.
Task 6
🔴 Critical — Trust Core
SequenceMatcher.ratio() rejects valid verbatim quotes
ratio() penalises length difference: a verbatim excerpt of a long chunk scores ~0.63, far below the 0.85 threshold. The only way to score ≥0.85 would be to quote the entire chunk — defeating the purpose of citation excerpts entirely.
Fix: Quote-coverage = fraction of the quote's characters found in the chunk. Verbatim=1.0, near-verbatim(typo)=0.99, fabricated=0.63. Threshold 0.85 now correctly passes real citations and rejects hallucinated ones.
Final Review
🔴 Critical — Governance
Redaction fallback leaked unredacted PII to HITL gate
The supervisor's typed fallback for redaction stage returned case.response.letter verbatim. Emails, phone numbers, postcodes, and staff numbers could reach the human decision screen without redaction.
Fix: Import and call redact_with_regex inside _redaction_fallback, matching the agent's own internal fallback. Unredacted PII at the HITL gate undermines the entire governance contract.
Post-build run
🔴 Critical — Cost Tracking
case.costs always [] in result JSON
get_usage_metadata_callback captured usage correctly and cost.entries accumulated fine — but process_request never assigned case.costs. Every result JSON had "costs": []. Masked by unit tests which use RunnableLambda fakes (no real usage metadata).
Fix: One line — case.costs = list(_request_entries) using the per-request slice. Live run verified: 4 cost entries ($0.046) in result JSON. Lesson: only a real-API smoke run surfaces cost-capture gaps.

Embedding model
Validated
nomic-embed-text-v1.5
Day-1 gate confirmed: dim=768, cosine(s40-query, s40-doc)=0.92. MiniLM fallback not needed. gte-base was originally proposed but also requires trust_remote_code — the stated advantage was wrong.
Compliance model tier
Operator override
Sonnet 4.6 (not Opus)
HTML planner's recommended default was Opus 4.8. Operator downgraded via dropdown — a cost/quality call the AI would not have made unprompted. Validated: Sonnet handles IRAC analysis adequately.
HITL cost display
Operator override
Hidden at gate; in logs only
Toggle show_cost: false in HTML planner. Rationale: showing cost at the decision point introduces automation bias (officers may approve to save money). Cost surfaces only in end-of-run summary and audit trail.
Retry strategy
Settled
.with_retry() only, stop_after=4
Rejected tenacity (extra dependency) and SDK retries (double-counting). Single LangChain .with_retry() wrapping the structured runnable. Clean, one mechanism, matches the ratified single-seam principle.
Audit format
Operator override
JSONL (primary) + .txt (secondary)
Planner note switched primary format from JSONL to .txt. Reconciled to dual-format: JSONL for programmatic processing, .txt for human-readable audits. Append-only across sessions (Agent-David governance contribution).
Agent unit-test seam
Plan deviation
RunnableLambda DI (not FakeListChatModel)
Plan specified FakeListChatModel. Verified before writing: its with_structured_output() raises NotImplementedError. Switched to dependency injection — every agent takes llm: Runnable | None = None; tests inject a lambda.
Grounding gate / injection defence
Novel
Citation failure → force withhold
Prompt delimiters reduce injection but can't eliminate it. Post-processing runs verify_citations; on any failure forces recommendation="withhold". A fully injection-flipped "release" citing a fabricated chunk is structurally blocked — not prompt-reliant.

Key Learnings
What the team learned
01
Unit tests with fake LLMs cannot validate cost capture
RunnableLambda fakes emit no usage_metadata, so cost.entries is legitimately empty in all unit tests. The only way to catch "costs never assigned" is a mandatory real-API smoke run. This should be a required acceptance gate on any LLM system.
02
Verify library APIs against installed versions before writing code
Three bugs (composition order, FakeListChatModel, SequenceMatcher L2 metric) came from trusting the plan's API sketches. Context7 + verifying against actually-installed packages caught all three before code was shipped.
03
TDD is the only reliable way to catch trust-critical correctness bugs
The IGNORECASE chunker bug (splits wrong exemption boundaries) and the SequenceMatcher metric bug (rejects valid verbatim quotes) were both silent — no error, just wrong behaviour. Tests named to the invariant caught them; manual inspection would have missed them.
04
Structural defences beat prompt-level defences for governance
Prompt injection hygiene reduces but cannot eliminate attacks. Making grounding-gate failure unconditionally force "withhold" means even a fully compromised LLM output citing fabricated chunks is blocked deterministically — the defence is in the code, not the prompt.
05
Interactive HTML planners elicit genuine operator decisions
The HTML brainstorm planner converted an open-ended "design this" into discrete, attributable choices (dropdown, toggle, notes). Five operator overrides materially changed the spec — including one the AI would never have made unprompted (downgrade compliance model).
06
Parallel independent specs + neutral collation beats consensus drafting
Four agents producing genuinely independent specs uncovered real disagreements (langchain vs plain SDK, HITL focus, cost display) that would have been smoothed over in a collaborative draft. The collator's job became clearer because the disagreements were explicit.
07
Sequential numbering is a merge-conflict magnet for parallel agents
The original AI_LOG format used global sequential headers (Prompt 0, Prompt 1…). With multiple agents appending simultaneously on different machines, collisions are inevitable. Attributed+dated headers (## [AgentName] YYYY-MM-DD) need no central counter and merge cleanly.
08
CPU-only torch install is a first-class dev environment concern
On a disk-constrained lab box, the default pip install of sentence-transformers pulls ~1.9 GB of CUDA wheels. Installing torch CPU-first reduces this to ~190 MB. This is now documented in the README quick-start as a required step, not an edge case.
