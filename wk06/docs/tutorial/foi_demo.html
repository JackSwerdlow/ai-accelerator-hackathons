the surprise

Type a quote. The system tells you if the model made it up.

The compliance agent must back every exemption claim with a verbatim quote from a retrieved policy chunk. A deterministic Python verifier — not the LLM grading itself — checks two things: L1 the cited chunk was actually retrieved, and L2 the quote really appears in it (≥ 85% character coverage). patterns to steal

Nine ideas you can lift into your next agentic system.

01
One state object, one schema per stage.
Pause, persist, audit, or resume at any boundary.
02
One LLM seam for every agent.
structured(build_llm) → with_retry. Order matters.
03
DI by keyword-only Runnable.
Production calls the model. Tests inject a lambda. Same code path.
04
Pure-Python verifier for every structured claim.
The model never grades itself. Trust comes from what can't lie.
05
Defence in depth on safety transforms.
Regex + LLM. Both pass, or it ships to a human.
06
Five reliability layers, each catching a distinct class.
Retry / typed fallback / try-except / breaker / batch isolation.
07
Hard-fail on missing operator identity.
Governance > convenience. No default, no fallback, no override.
08
Append-only audit, secrets scrubbed at write time.
Never trust callers to scrub.
09
Eval is a strict subset of the pipeline.
Skip the human, skip the letter. Measure what you can ground-truth.
