Export & save

“Save to this file” writes your ticks, choices, notes, and editable config blocks straight into the markdown markers above (so a git diff reads as plain content), and your names & owners into the state block (Chrome/Edge). You pick the file once per session; reopen the saved file to see your changes. Other browsers: use “Generate & copy JSON” and paste it back. The file only changes when you click — a field edit alone can't rewrite a file on disk.
