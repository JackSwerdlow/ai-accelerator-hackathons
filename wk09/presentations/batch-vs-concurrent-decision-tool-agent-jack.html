Where the money actually goes

A fair comparison adds three things no per-token price shows on its own.

API cost

Tokens × price per request. Batch is billed at 50% off; sequential and concurrent pay the full token rate.

Cost of waiting

Every hour results aren't ready has a price — blocked downstream work, an SLA, or a person idle. Paid per hour of wall-clock.

Manual labour

The do-nothing-with-AI baseline: pay people to read and tag each response by hand. Sometimes, at tiny volumes, still the cheapest.

The trade

Batch trades speed for price. It wins when nobody's waiting; it loses the moment the delay costs more than the token saving.

What's hardcoded (and why)

  • 50% batch discount — a fixed industry constant (Anthropic, OpenAI, Google all use it).
  • Both API modes need ~0.3 h oversight — someone kicks the run off and checks results.
  • Batch time is treated as ~flat (async SLA), not linear in volume — unlike concurrent, which scales with the number of waves.
