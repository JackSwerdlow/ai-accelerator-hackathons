Checklist S5 · analyse.py

Two processes, one temp filename

What happened

Two people running analyse.py at the same time against the same output crashed with a bare FileNotFoundError — reproduced roughly 1 time in 5-6, reliably, before the fix.

FileNotFoundError: [Errno 2] No such file or directory: '.batch_state.tmp' -> '.batch_state.json'

Root cause — two stages, not one

1. _save_state's temp file path (state_file.with_suffix(".tmp")) was identical for both processes sharing a state file — one process's write-then-rename raced the other's.
2. Fixing that unmasked a second, masked race: _clear_state's exists-then-unlink was its own TOCTOU gap, only visible once the first race stopped hiding it.

Fix

Per-process temp filenames (state_file.with_suffix(f".{os.getpid()}.tmp")) for atomic per-process writes; _clear_state made idempotent (try: unlink() except FileNotFoundError: pass).

✓ 100+ trials, 0 crashes

tests/system/test_operability.py — 6 trials × 12 concurrent-process attempts. Before the fix: crashed reproducibly. After: zero.

Spend-tracker · log_claude_code_session.py

Same disease, different file

What happened

Two ordinary Claude Code turns were logged at £16.37 and £23.41 — flagged by a human as obviously implausible for routine work, discovered while investigating a separate, unrelated question about a mislabelled "Purpose" column.

Root cause

An unlocked, shared spend_tracking_state.json racing across concurrent Claude Code sessions on the same machine — the same class of bug as S5 (a shared-state race), independently discovered in a completely different file.

Fix

A _StateLock (fcntl.flock) around every read-modify-write; atomic _save_state (write-temp-then-rename, no shared temp path); a persisted, bounded billed_ids dedup set (last 2,000) so a lost state update can never double-bill the same usage twice; migration for the old int-only state format.

✓ 4 regression tests, all green

tests/unit/test_spend_logging.py — dedup-across-lost-updates, concurrent-invocation locking, legacy-format migration.

Neither bug was hunted for directly — both surfaced from reconciling two pieces of independent, concurrent work against each other. That's the case for doing it, not a coincidence.
