"Batch" and "concurrent" are different tools — batch trades speed for cost; concurrency doesn't trade anything. Use batch for the job nobody's waiting on; use concurrent/sync for anything someone is.

Not an Anthropic quirk — OpenAI's Batch API and Google's Gemini Batch Mode use the identical shape: 50% off, ~24h target, usually much faster in practice.
