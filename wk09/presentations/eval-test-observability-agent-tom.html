Wrote the 57-item checklist + test suiteWritten first
A 57-item hardening checklist (security, resilience, PII, cost, governance…) plus a test suite that pins the original prototype's real bugs as failing tests — written before any fix code existed.
Rewrites analyse.py from scratch, in parallel
A full rewrite of the exact file the test suite was being written against, done concurrently and independently. Could have made the suite redundant — instead, reconciling the two is what surfaced a real bug.
Reconciliation finds a real race
Two people running the analyser at once raced on an identical temp filename.FileNotFoundError: [Errno 2] No such file or directory: '.batch_state.tmp' -> '.batch_state.json'Reproduced roughly 1 time in 5-6, reliably.
Same shape, different file
Two ordinary Claude Code turns logged as £16.37 and £23.41 — an unlocked, shared state file racing across concurrent sessions. Same disease as the analyser bug, in a completely different file. Fixed with a file lock, an atomic write, and a persisted dedup set.
Both races fixed
Fixing the temp-file collision stopped hiding a second, masked race in the cleanup path (an exists-then-unlink gap). Both are fixed and now covered by dedicated regression tests.
100+ trials, 0 crashes
A concurrent-run stress test, repeated 100+ times after the fix: zero crashes. Before the fix, the same test reproduced the crash roughly 1 time in 5-6.
Now observable
Every run now emits real OpenTelemetry traces, 5 metrics (spend, rows by outcome, cache status, response size, batch rows) and structured, PII-safe logs — not just a pass/fail result.
